I build practical software, AI tools, and data integrations through **SOFTech Integrations LLC**. Lately I’m focused on developer workflows and applications that give people more control over their data and automation.

## A few things I’ve built and explored

- **[ResumeArchitect](https://github.com/Jnich145/ResumeArchitect)** — a local resume editor with live layouts, explicit browser saving, portable JSON files, and print/PDF output. [Reproducible checks](https://github.com/Jnich145/ResumeArchitect/blob/main/docs/validation.md) cover the core workflow; the older AI/backend prototype is preserved separately.
- **[AutomatedEmail](https://github.com/Jnich145/AutomatedEmail)** — an earlier experiment in research-assisted outreach drafting. It generates text; it does not send email.
- **[yt-dlp GUI](https://github.com/Jnich145/yt-dlp)** — my experimental PyQt6 interface in a fork of the upstream [yt-dlp](https://github.com/yt-dlp/yt-dlp) project.
- **[ACOG](https://github.com/Jnich145/ACOG)** — an experimental content orchestration stack with an API, workers, and a dashboard.

These projects reflect different stages of learning and development. Their READMEs describe what is implemented, what is experimental, and what still needs work.
